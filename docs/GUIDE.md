# VibeTabula — инструкция

VibeTabula — пространственный рабочий стол для нейросетей. На бесконечном поле (canvas) живут окна агентов, чаты, заметки, стикеры, фигуры и стрелки между ними. У каждого проекта может быть сколько угодно canvas.

---

## 1. Запуск

**Готовая версия:** скачайте установщик `VibeTabula-Setup-x.y.z.exe` или портативный `VibeTabula-Portable-x.y.z.exe` на странице [Releases](https://github.com/SashaVasyanov/CanvasTTY/releases). Node.js не нужен. Установщик сам создаст ярлык на рабочем столе. Для портативной версии рядом с exe можно положить `scripts/create-shortcut.cmd` и запустить его.

**macOS:** скачайте `VibeTabula-x.y.z-mac-arm64.dmg` для Mac на Apple Silicon (M1–M4) или `…-mac-x64.dmg` для Mac на Intel, откройте и перетащите VibeTabula в «Программы». Сборка не подписана сертификатом Apple, поэтому при первом запуске нажмите на приложение правой кнопкой → «Открыть» → «Открыть». Если macOS пишет, что приложение «повреждено», выполните в Терминале `xattr -cr /Applications/VibeTabula.app`. Для встроенного терминала нужен `python3`: если его нет, macOS предложит установить Command Line Tools (или выполните `xcode-select --install`). Окна чата агентов работают и без него.

**Из исходников** (нужен Node.js 20+): `npm install`, затем `npm start`.

При первом открытии терминала Windows один раз за пару секунд собирает маленький вспомогательный файл `ptybridge.exe` (мост к консоли Windows). Дальше терминалы открываются сразу.

## 2. Из чего состоит экран

- **Заголовок окна.** Слева название и версия. В центре выбор проекта и вкладки canvas (`+` — новый canvas). Справа: боковая панель, поиск команд, лимиты, переключатель темы ☀/☾, инструкция «?», настройки.
- **Пульт агентов** — виджет в центре canvas: лимиты нейросетей, статусы агентов, часы, питомец и док с кнопками запуска.
- **Миникарта и масштаб** — слева сверху. Кнопка с картой (или клавиша `M`) скрывает и показывает миникарту.
- **Панель инструментов** — снизу: выделение, рука, стикер, текст, фигуры, стрелка, область, комментарий, заметка, изображение, виджеты и зелёная кнопка «Агент».
- **Боковая панель** (`Ctrl+\`) — canvas текущего проекта, дерево заметок, поиск, теги.

---

## 3. Проекты и canvas

- Проект — это набор canvas и **рабочая папка**: в ней запускаются агенты. Меню проекта открывается кликом по названию в заголовке. Там же «Новый проект…» и «Настройки проекта…» (имя, цвет, рабочая папка).
- Вкладки сверху — canvas текущего проекта. Двойной клик по вкладке переименовывает её, ПКМ открывает меню (дублировать, перенести в другой проект, удалить), колёсико по вкладке удаляет.
- Всё сохраняется автоматически.

## 4. Работа с объектами

| Действие | Как |
| --- | --- |
| Перемещаться по полю | пробел + тянуть, средняя кнопка мыши, инструмент «Рука» (H) |
| Масштаб | колесо мыши, Ctrl + колесо, кнопки слева сверху |
| Выделить | клик, Shift + клик, рамка по пустому месту |
| Двигать | тянуть объект (окна — за заголовок). Shift — только по оси, Ctrl — без привязки |
| Дублировать перетаскиванием | зажать Alt и тянуть выделенное (как в Figma): оригинал остаётся на месте, тянется копия |
| Двигать за любое место | двойной клик по окну, заметке, чату или области (инструмент «Выделение»): объект выделится пунктиром, и его можно тянуть откуда угодно. Ещё один двойной клик или Esc — снова работать с содержимым |
| Размер | маркеры по углам и сторонам, Shift — сохранить пропорции |
| Соединить стрелкой | точки по краям выделенного объекта или инструмент «Стрелка» (A) |
| Создать связанный объект | протянуть стрелку на пустое место — появится меню |
| Выделить несколько | рамкой по пустому месту, Shift+клик или Ctrl+A. Вокруг выбранных — тонкая общая рамка с подписью «Выбрано: N», каждый выбранный объект обведён. Их можно вместе двигать, выравнивать, группировать в область (Ctrl+G), дублировать и удалять |
| Выровнять, распределить | панель над выделением, когда выбрано 2+ объекта |
| Сгруппировать в область | Ctrl+G (если в выделении есть область — остальное добавляется в неё) |
| Закрепить | Ctrl+L или замок на панели над выделением. Закреплённый объект не двигается и не выделяется по клику: в закреплённом чате или терминале можно спокойно печатать без рамки выделения и панели сверху, клик по стикеру или картинке работает как клик по пустому месту. Открепить — маленький замок в заголовке окна (у стикеров и картинок — в углу при наведении), ПКМ → «Открепить» или Ctrl+клик и Ctrl+L |
| Слои | `[` и `]` |
| Копировать, вырезать, вставить, дублировать | Ctrl+C / X / V / D |
| Отменить, повторить | Ctrl+Z / Ctrl+Shift+Z |
| Новый стикер | S или кнопка стикера на нижней панели |
| Рисование | P или кнопка с карандашом. Над панелью появляются инструменты как в «Заметках» Apple: ручка, маркер (полупрозрачный), карандаш и ластик (E — стирает линии, которых коснётся). Повторное нажатие на выбранный инструмент — толщина и прозрачность. Цвета — системная палитра Apple (оттенки подстраиваются под тему), радужный кружок — спектр, пипетка, HEX и «Мои цвета». Shift — прямая линия. Нарисованное — обычный объект: выделяется кликом по линии, двигается, растягивается, перекрашивается на панели над выделением |
| Комментарий | C или кнопка с облачком: клик в нужное место (на объект — комментарий будет ездить вместе с ним), текст, Enter. Наведение на значок показывает автора, время и текст, клик открывает ветку с ответами, ✓ — решено. Значок можно перетащить. Shift+C или ПКМ по кнопке — скрыть / показать комментарии, показывать решённые, изменить подпись |
| Править текст, стикер, фигуру | клик по уже выделенному объекту (курсор встанет туда, куда кликнули), двойной клик или Enter. Инструмент «Текст» (T) по существующему тексту тоже открывает его для правки |
| Размер шрифта текста | поле с числом на панели над выделением: введите размер, ↑/↓ (Shift — по 10), колесо мыши, кнопки − / + или список готовых размеров. Работает и для нескольких текстов сразу |
| Меню объекта | ПКМ или «⋯» в заголовке окна |
| Размер текста в окне чата | Ctrl + / Ctrl − в поле ввода, Ctrl 0 — как в настройках |

Можно перетащить на canvas картинку или `.md` файл из проводника, а также вставить из буфера картинку, ссылку или текст.

### Области с названиями
Инструмент «Область» (F) — цветная скруглённая зона с крупным названием, например «Фото проекта 1». Нарисуйте её мышью или выделите объекты и нажмите Ctrl+G. Двойной клик по названию или ПКМ → «Ввести название…» переименовывает область, цвет меняется на панели над выделением. Чтобы выделить область, нажмите на её название или дважды кликните по пустому месту внутри неё — тогда её можно перетаскивать за любое место.

**Область — это группа.** Объект, который вы положили в область (его центр внутри неё), становится её частью: справа сверху видно, сколько в ней объектов, а при перетаскивании объекта область, в которую он попадёт, подсвечивается пунктиром. Двигаете область — едет всё содержимое, даже если что-то немного торчит за край. Вытащили объект наружу — он покидает группу. Области можно вкладывать друг в друга. Копирование и дублирование области копирует её вместе с содержимым.

ПКМ по области:
- **Сгруппировать: двигать как одно целое** — клик по любому объекту внутри выделяет всю область, и группа двигается целиком. Чтобы выбрать отдельный объект, кликните с зажатым Ctrl. Повторный выбор пункта отключает режим.
- **Выделить содержимое** — выделить все объекты внутри.
- **Разгруппировать** — убрать область, объекты останутся на месте.
- **Удалить вместе с содержимым**.

### Виджеты
Кнопка «Виджеты» на нижней панели (или клавиша W, или ПКМ по пустому месту → «Виджет») добавляет на canvas живой мини-инструмент:
- **Часы** — время и дата в стиле StandBy (цвета как у часов на пульте), можно выбрать часовой пояс (ПКМ → «Часовой пояс…»).
- **Таймер** — обратный отсчёт и помодоро: 5 / 15 / 25 / 50 минут или своё время, уведомление по окончании. Идёт, даже если закрыть приложение.
- **Чек-лист** — список дел с прогрессом: Enter добавляет задачу, клик по квадрату отмечает.
- **Календарь** — месяц с сегодняшним днём, стрелки листают, клик по названию месяца возвращает к сегодняшнему. Клик по дню открывает заметку на этот день и выбор цвета (цвета Apple или свой из спектра): отмеченный день подсвечивается цветом, у дня с заметкой — точка, текст виден при наведении, а в большом календаре — прямо в клетке. Ctrl+Enter или «Готово» — сохранить; в меню виджета — «Очистить заметки месяца».
- **До события** — сколько дней осталось до даты (релиз, дедлайн), за 3 дня число краснеет.
- **Агенты** — кто из агентов на этом canvas работает, ждёт ответа или закончил; клик — перелететь к окну.
- **Лимиты** — остатки подписок и API-ключей.
- **Секундомер** и **Счётчик**.

Виджет — обычный объект: двигается, растягивается (содержимое масштабируется), копируется, попадает в области и синхронизируется вместе с canvas. Двойной клик или ПКМ — настройки виджета.
### Часы в пульте
В пульте агентов часы в стиле режима StandBy на iPhone: крупные округлые цифры, которые заходят друг на друга, и дата под ними.

**Цвета** настраиваются отдельно для тёмной и светлой темы: Настройки → Общие → «Часы в пульте» или ПКМ по часам. Готовые наборы: StandBy (синий, по умолчанию в тёмной теме), Закат, Мята, Фиалка, Неон, Графит и светлые Бумага (по умолчанию в светлой теме), Небо, Персик, Сирень, Матча. В «Свои цвета» задаются фон, каждая из четырёх цифр, точки и дата.

При сильном отдалении окна превращаются в карточки с названием и статусом: заметки, терминалы и браузер — меньше 30 %, чаты с нейросетями — только меньше 20 %, чтобы переписку было видно издалека. Пороги настраиваются: Настройки → Общие → «Карточки при отдалении» и «Чаты нейросетей при отдалении». Если окон очень много и холст подтормаживает, сдвиньте ползунки вправо.

**Размер текста в чатах.** Переписка и поле ввода в окнах чатов с агентами и API-чатов — 14 px; изменить для всех окон: Настройки → Общие → «Размер текста в чатах». Для одного окна: Ctrl + / Ctrl − в его поле ввода (Ctrl 0 — вернуть как в настройках) или меню окна → «Размер текста». Когда холст отдалён, текст в чатах сам укрупняется, чтобы на экране он оставался не мельче 12 px (но не больше чем втрое): во время движения он уменьшается вместе с холстом, а когда масштаб перестаёт меняться — становится читаемым. Окно по-прежнему показывает последнее сообщение. Выключить: Настройки → Общие → «Читаемый текст при отдалении».

## 5. Нейросети: три способа

### 5.1. Окно чата агента — как в их приложениях (рекомендуется)

Это обычный чат, но под капотом работает CLI-агент **по вашей подписке**, без API-ключа:
- **Claude Code** — нужна подписка Claude (Pro/Max) или вход через Anthropic Console;
- **Codex** — нужна подписка ChatGPT (Plus/Pro) или ключ OpenAI, через который вы вошли в Codex.

Как открыть:
1. В доке пульта нажмите на значок агента (**Cl** — Claude Code, **Cx** — Codex) → «Окно чата».
   Или зелёная кнопка «Агент» → раздел «Чат с агентом».
2. Напишите задачу и нажмите Enter.

В окне видны ответы агента и его действия: команды, правки файлов, поиск. Их можно раскрыть и посмотреть вывод.

Сверху в окне:
- **Модель** — какой моделью работает агент. «Авто» берёт модель из настроек самого агента (в скобках показано, какая именно). У Claude Code на выбор Opus, Sonnet, Haiku и Fable 5.1, у Codex — модели из его списка. Пункт «Другая…» позволяет вписать любое название, например `claude-opus-5-5`.
- **Размышление** — насколько долго модель думает перед ответом (reasoning effort): от «Низкого» до «Максимального» у Claude и от «Минимального» до «Очень высокого» у Codex. Выше уровень — точнее на сложных задачах, но медленнее и быстрее тратит лимиты. Если установленная версия Claude Code не поддерживает выбор уровня, окно сообщит об этом и отправит задачу без него.
- **Доступ** — что агенту разрешено. У Claude: «Правки файлов», «План, без изменений», «Полный доступ», «Только чтение». У Codex: «Правки в папке», «Только чтение», «Полный доступ». «Полный доступ» разрешает агенту выполнять любые команды без подтверждения, включайте его осознанно.

Под ними строка состояния: слева **рабочая папка** агента (по умолчанию папка проекта; клик меняет её для этого окна, полный путь — во всплывающей подсказке), справа — **модель и уровень размышления**, с которыми работает окно. После первого ответа там появляется точное название модели, которое сообщил сам агент.

- **+** — новая сессия: агент забудет переписку.

**Файлы и картинки.** В любой чат (с агентом и по API) можно приложить файлы: скрепка слева от поля ввода, перетаскивание файлов на окно чата, **перетаскивание картинки с холста на окно чата** (окно подсветится; картинка приложится к сообщению и вернётся на своё место) или вставка картинки из буфера (Ctrl+V, например скриншот; если окно чата выделено, картинка уйдёт в него, а не на холст). Над полем ввода видны превью; крестик убирает вложение. В переписке картинки показываются миниатюрами (клик — просмотр на весь экран), остальные файлы — карточками с типом и размером (клик открывает файл).

**Картинки, которые рисует Codex.** Codex сохраняет сгенерированные картинки в свою папку: `C:\Users\<вы>\.codex\generated_images\<номер сессии>\` (на macOS и Linux — `~/.codex/generated_images/…`). VibeTabula сам находит новые картинки сессии и показывает их прямо в ответе. По клику картинка открывается на весь экран. Кнопка «На холст» кладёт её рядом с чатом (она сохраняется в хранилище заметок, в папку `attachments`), кнопка «Показать в папке» открывает файл. Вся папка с картинками сессии: ПКМ по окну чата → «Папка с картинками Codex».

**Поиск по всему (Ctrl+K).** Одно окно ищет сразу везде: объекты всех холстов всех проектов (стикеры, тексты, фигуры, области, чек-листы, названия окон, картинок и заметок), переписку в окнах чатов (и старые сообщения, спрятанные за «Показать предыдущие»), заметки по тексту, разговоры из истории чатов и вывод терминалов, открытых на этом холсте. Должны встретиться все слова, в любом порядке и регистре. Результаты сгруппированы, справа видно, где лежит объект («этот холст» или «Проект / Холст»), найденные слова подсвечены. ↑/↓ — выбрать, Enter — перейти: VibeTabula откроет нужный холст, подлетит к объекту и мигнёт рамкой; в чате прокрутит к сообщению и подсветит слова; заметку откроет в редакторе; разговор из истории откроет в новом окне чата (или в том, где он уже открыт); в терминале выделит найденную строку. В поле ввода и в терминале Ctrl+K остаётся их сочетанием (ссылка в заметке, удаление строки), из терминала — Ctrl+Shift+K. Также: поиск команд Ctrl+P → «Поиск по всему…».

**Спросить нескольких.** Один вопрос сразу двум или трём агентам или моделям: меню окна чата → «Спросить нескольких…» (или поиск команд Ctrl+P). В окне выберите, кому задать вопрос (например, Codex и Claude Code или две модели Claude). Рядом откроется область «Сравнение» с окнами, и каждому уйдёт тот же вопрос с тем же контекстом исходного окна (стрелки и @). Если папка под git, у каждого будет своя копия проекта (git worktree), и агенты не правят одни и те же файлы. Под последним ответом каждого окна есть кнопка «Выбрать этот ответ»: выбранное окно остаётся, изменения его копии вливаются в вашу ветку (при конфликте ничего не меняется), остальные окна закрываются (переписка остаётся в истории чатов), их копии удаляются.

**Стрелка «Передавать ответ».** Стрелку между двумя окнами чата (агенты или API-чаты) можно превратить в конвейер: ПКМ по стрелке → «Передавать ответ». Когда первый закончит ответ, второй сам получит его следующим сообщением и начнёт работать. Над таким сообщением видно, от кого оно пришло, а стрелка подсвечивается, пока ответ «едет». «Приписка к ответу…» задаёт текст перед ответом, например «Проверь этот код и найди ошибки» (по умолчанию «Ответ от «…»:»). Так строится цепочка «план → код → ревью». Если второй ещё занят, ответ дождётся конца его работы. Ошибки, остановленные и прерванные ответы не передаются. Защита от зацикливания: без вашего участия передаётся не больше 5 ответов подряд, а если вы напишете сами, счёт начинается заново. «Стоп» в любом окне цепочки останавливает и остальные её окна. Если холст закрыт, когда первый закончил, ответ запишется второму и уйдёт, когда вы откроете этот холст. Такая стрелка не работает как контекст: ответ и так приходит сообщением.

**Шаблоны раскладки.** Готовая расстановка объектов со связями вставляется одним кликом: правый клик по пустому месту холста → «Шаблон раскладки…» (или поиск команд Ctrl+P → «Шаблоны раскладки…», «Шаблон: Баг»). Встроенные: **«Баг»** — область «Описание бага» со стикерами «Что сломалось», «Как воспроизвести», «Ожидалось / на деле», стрелка к Claude Code «Исправление бага» и стрелка «Передавать ответ» к Codex «Проверка исправления»; **«Фича»** — описание, Claude Code в режиме «План», Codex «Реализация» по плану и чек-лист «Готово, когда»; **«Ревью»** — что проверить и два агента, которые смотрят изменения ветки с разных сторон (только чтение), плюс стикер «Итог ревью». В окнах агентов уже написана стартовая задача: заполните стикеры и нажмите Enter в окне. Шаблон встаёт там, где вы кликнули правой кнопкой (или в центре экрана), вставленное выделено, Ctrl+Z убирает его целиком. Свой шаблон: выделите объекты или область (она берёт с собой содержимое) → правая кнопка → «Сохранить как шаблон…». В шаблон попадают объекты, их места, размеры, цвета и стрелки. Не попадают переписка и сессии чатов, рабочие папки и копии проектов: окна вставляются чистыми. Заметки сохраняются с текстом, и при вставке каждая становится новой заметкой в папке «Из шаблонов». Свои шаблоны переименовываются и удаляются в том же окне (кнопки на карточке при наведении) и синхронизируются между компьютерами вместе с проектами. Если вставить шаблон второй раз, области и окна получают номер: «Фича 2».

**Агент работает с холстом.** Агенты в окнах чата (Codex и Claude Code) видят холст, на котором стоит их окно, и могут сами добавлять на него объекты. Попросите, например: «разложи план релиза по шагам на холсте» или «собери идеи из этого разговора в стикеры и сгруппируй». Агент посмотрит, что уже лежит на холсте, прочитает нужные объекты (текст стикеров, заметки, ответы других чатов, содержимое областей) и добавит рядом со своим окном стикеры, тексты-заголовки, заметки (они сохраняются в хранилище, в папку «Из чатов»), области и стрелки с подписями. Новые объекты встают справа от окна агента и не наезжают на ваши; если агент кладёт их в область, она растёт под содержимое. Менять агент может только то, что добавил сам из этого окна. Ваши объекты и объекты других чатов он не правит и ничего не удаляет. Всё, что агент добавил за один ответ, убирается одним Ctrl+Z (о добавлении сообщает всплывающая подсказка). Если между добавлениями агента вы сами что-то меняли, Ctrl+Z идёт по шагам: сначала то, что агент добавил после вашей правки, потом ваша правка. Если холст сейчас не открыт (вы ушли на другой), агент работает с его файлом, и вы увидите результат, когда откроете холст. Выключить: Настройки → Агенты → «Инструменты холста для агентов»; новые сообщения уйдут агенту без этих инструментов, а уже работающий агент получит отказ.

**Отдельная копия проекта (git worktree).** Чтобы агент не трогал вашу папку, пока работает, — меню окна (ПКМ по заголовку) → «Работать в отдельной копии». Агент получает свою ветку `vibetabula/<название>` и свою папку рядом с проектом (`<проект>.worktrees/<название>`); в копию попадает последний коммит, ваши незакоммиченные правки остаются у вас. Несколько агентов в одном репозитории так не мешают друг другу. В окне видна плашка с веткой и тем, сколько у агента коммитов и файлов без коммита; клик по ней — действия: «Изменения копии» (карточка с diff), «Влить в «main»» — сначала показывает изменения, после подтверждения то, что агент не закоммитил, становится коммитом на его ветке и вливается в ветку вашей папки; при конфликте или если мешают ваши незакоммиченные правки ничего не меняется, а VibeTabula показывает, в каких файлах дело. «Удалить копию» удаляет её папку (о несохранённых изменениях агента предупредит отдельно); ветка удаляется, если уже влита, иначе остаётся. При включении копии агент начинает новую сессию.

**Что изменил агент.** Если рабочая папка агента — git-репозиторий, после ответа под ним появляется строка «Изменено 3 файла +42 −7». «Показать» открывает рядом с чатом карточку изменений: список файлов (новый, изменён, удалён) и diff каждого с подсветкой добавленных и удалённых строк; кнопка с папкой показывает файл в проводнике. «Откатить» (после подтверждения) возвращает файлы этого ответа к состоянию до него: файлы, которые после ответа правили вы или другой агент, не трогаются (о них будет сказано), созданные агентом файлы уходят в корзину. «Вернуть» отменяет откат. Ваша ветка, индекс git и ваши незакоммиченные правки не меняются — VibeTabula делает снимок папки во временном индексе. В режимах «Только чтение» и «План» снимок не делается. Для папок не под git видно только, какие файлы трогал агент, без diff и отката. Если в папке тысячи файлов, которые git не игнорирует (например, node_modules без .gitignore), изменения не отслеживаются.

**Ждут вас.** Колокольчик вверху справа показывает, сколько чатов закончили работу, пока вы были в другом месте: агент ответил, ждёт разрешения, упал с ошибкой или прервался (API-чаты тоже). В списке видно имя окна, на каком холсте оно стоит, что случилось и начало ответа. Клик открывает нужный проект и холст и подводит камеру к окну. Чат пропадает из списка, когда вы кликнули в окно или отправили ему новое сообщение. Если ответ закончился у вас на глазах, в список он не попадает. Учитываются окна на всех холстах, в том числе агенты, которые закончили в фоне при закрытом приложении. Список сохраняется после перезапуска. Когда VibeTabula не в фокусе, приходит системное уведомление (клик ведёт к окну) и мигает кнопка на панели задач; выключается в Настройки → Агенты → «Уведомлять, когда агент закончил».

**Следующий ждущий агент (Ctrl+J).** Окна из «Ждут вас» на холсте обведены пульсирующей рамкой: жёлтой — нужно ваше решение (разрешение, прервано), красной — ошибка, зелёной — готово. Ctrl+J перелетает к следующему такому окну на любом холсте любого проекта: сначала те, что ждут решения, потом ошибки, потом готовые, внутри — от самого давнего. Всплывающая подсказка говорит, сколько ещё ждут. Окно уходит из списка и теряет рамку, когда вы к нему перелетели, кликнули в него, написали ему или просто задержали на нём взгляд: камера остановилась, окно почти целиком на экране и масштаб не мельче 45 %. Из терминала — Ctrl+Shift+J, также «Следующий ждущий агент» в поиске команд.

**Что сейчас делает агент.** Рядом с названием окна чата — одна строка: что агент делает прямо сейчас и сколько уже работает: «Запускает npm test · 2 мин», «Правит README.md», «Читает package.json», «Ищет «TODO»», «Добавляет стикер на холст», «Думает…», «Пишет ответ…». Строка меняется по ходу ответа; длинная команда обрезается, но время видно всегда, полный текст — в подсказке при наведении. После ответа там итог: «Готово за 2 мин · 3 файла» (сколько файлов изменил агент), «Остановлено через 40 с» или «Ошибка через 1 мин». То же показывают карточка окна при сильном отдалении, пульт агентов и виджет «Агенты». Если агент закончил в фоне при закрытом приложении, время считается до настоящего конца ответа, а не до момента, когда вы открыли окно. У API-чатов — «Думает…», «Пишет ответ…» и такой же итог.

**Закрыли приложение, пока агент отвечает.** Агент в окне чата продолжает работу в фоне: Codex или Claude Code дописывает ответ, даже если VibeTabula закрыт или перезагружен. При следующем запуске окно чата показывает «Работает» и подхватывает ответ, а если агент уже закончил — показывает ответ целиком. Если же агент остановился сам (компьютер выключили или перезагрузили), под ответом будет «Ответ прервался» и кнопка **«Продолжить»**: агент продолжит в той же сессии с того места, где остановился («Начать ответ заново» отправит вопрос ещё раз). Чтобы закрытие приложения останавливало агентов, выключите Настройки → Агенты → «Агент продолжает работать после закрытия приложения». Чаты по API так не умеют: если закрыть приложение во время ответа, под ним будет кнопка «Повторить».

**Ошибки — понятным языком.** Если агент или API-чат вернул ошибку, в чате написано, что случилось и что делать, с кнопками: «Войти» (откроет терминал со входом в Codex или Claude Code), «Повторить», «Модель «Авто»» / «Выбрать модель», «Настройки ключей», «Лимиты», «Режим доступа», «Новый чат» (если разговор не помещается в память модели), «Скопировать команду установки». Исходный текст ошибки — под «Подробности».

**«Связь с сервером OpenAI прервалась».** Если во время ответа обрывается соединение Codex с серверами OpenAI, Codex сам переподключается до 5 раз, а в чате видна одна жёлтая строка «переподключается (2 из 5)». Это не ошибка VibeTabula. Если все попытки не удались, придёт сообщение об ошибке: отправьте задачу ещё раз чуть позже, проверьте интернет и VPN или прокси, а при повторах — status.openai.com.
- Чаты по API получают картинки напрямую (модели с поддержкой изображений), PDF — у Claude и OpenAI, текстовые и кодовые файлы — вставкой содержимого.
- Claude Code и Codex получают пути к файлам и читают их сами (Claude Code открывает картинки и PDF инструментом Read, Codex получает картинки через `--image`).
- Файлы хранятся в папке данных VibeTabula (`attachments`), в сообщении остаётся маленькое превью, поэтому на другом компьютере после синхронизации картинки видны миниатюрами.

**Поиск по старым чатам.** Агенты в окнах чата (Claude Code и Codex) получают инструменты VibeTabula: `search_chats`, `read_chat` и `list_chats`. Ими агент сам ищет и читает ваши прошлые переписки: историю чатов VibeTabula и сессии Claude Code / Codex на этом компьютере, в том числе из терминала. Просто попросите: «найди в старых чатах список таблиц по UD». Инструменты только читают историю и работают локально.

**История чатов.** Кнопка с панелью слева в окне чата (или «⋯» → «История чатов») открывает список прошлых разговоров, как в приложениях ChatGPT и Claude. Каждый разговор сохраняется автоматически после ответа, сгруппирован по дням, есть поиск. Клик открывает чат, и следующее сообщение продолжит его. «Новый чат» начинает разговор с чистого листа, а текущий остаётся в истории.

Во вкладке **«Сессии Claude Code» / «Сессии Codex»** видны все сессии, которые агент хранит у себя на диске, в том числе запущенные в обычном терминале. По умолчанию показаны сессии текущей рабочей папки. Открытая сессия продолжится в своей папке.

Переписка продолжается в одной сессии агента. В длинных чатах показываются последние сообщения, кнопка «Показать предыдущие сообщения» сверху подгружает более ранние. Через меню окна «⋯» → «Открыть эту сессию в терминале» её можно продолжить в полноценном терминале.

> Перед первым использованием войдите в агента один раз: откройте его в режиме «Терминал» и выполните вход (у Claude Code команда `/login`, Codex спросит сам).

### 5.2. Агент в терминале

Полноценный терминал с CLI-агентом — тот же интерфейс, что в консоли. Док → значок агента → «Терминал», или кнопка «Агент» → «Агент в терминале». Кнопка `>_` открывает обычный PowerShell.

Статусы на заголовке и в пульте: **Работает** (агент что-то выводит), **Ожидает**, **Завершён**, **Статус недоступен** (CLI не установлен; в окне будет подсказка, как установить).

### 5.3. Чат по API-ключу

Классический чат через API провайдера. Платите за токены, подписка не нужна.

1. Получите ключ: Claude — на console.anthropic.com, OpenAI — на platform.openai.com, Kimi — на platform.moonshot.ai и т.д.
2. Вставьте его: **Настройки → API-провайдеры** → нужный провайдер → «API-ключ».
3. Откройте чат: кнопка «Агент» → «Чат по API-ключу» → провайдер. Для Claude можно и так: док → значок **Cl** → «Чат по API-ключу».

Поддерживаются: Claude (API Anthropic), OpenAI, Kimi (Moonshot), OpenRouter, DeepSeek, Gemini, Ollama (локально, без ключа) и любой OpenAI-совместимый сервер. Кнопка ⟳ рядом с моделью загружает список доступных моделей.


У чатов по API та же история: кнопка слева в окне.

### Как подключить именно Claude

| Способ | Что нужно | Где открыть |
| --- | --- | --- |
| Окно чата Claude Code | установлен Claude Code и выполнен вход (подписка) | док → **Cl** → «Окно чата» |
| Терминал Claude Code | то же | док → **Cl** → «Терминал» |
| Чат по API | ключ с console.anthropic.com | Настройки → API-провайдеры → Anthropic; затем док → **Cl** → «Чат по API-ключу» |

Установка Claude Code: `npm i -g @anthropic-ai/claude-code` (или нативный установщик с сайта Anthropic). Затем откройте «Терминал» Claude Code и выполните `/login`.

**Про MCP.** MCP не подключает саму нейросеть: это способ дать агенту дополнительные инструменты (базы данных, сервисы и т.п.). Серверы MCP настраиваются в самом агенте, например `claude mcp add …`, и автоматически работают в окнах чата и терминала VibeTabula.

### Контекст: стрелки и @

**Стрелка.** Соедините стрелкой с окном чата любой объект: область, заметку, картинку, стикер, текст, фигуру, другой чат, терминал, ссылку или виджет (чек-лист, календарь). Его содержимое уйдёт нейросети вместе с сообщением:
- **Область** передаёт всё, что лежит внутри неё, включая вложенные области: заметки, стикеры, тексты и картинки.
- **Заметка** уходит целиком, у терминала — последние строки вывода, у другого чата — его последний ответ.
- **Картинки** прикладываются к сообщению файлами, нейросеть их видит. Агенты (Codex, Claude Code) открывают их сами, API-чаты получают их как изображения.

**Упоминание через @.** Наберите в поле ввода `@` и начало названия: появится список объектов с холста (ближние к чату сверху). Стрелки ↑/↓ и Enter или Tab выбирают объект, Esc закрывает список. Можно набрать название и вручную: `@Карты мира`, `@Описание рельефа`. Упомянутый объект уходит в контекст только с этим сообщением.

Над полем ввода строка «Контекст» показывает, что уйдёт нейросети: объекты по стрелкам и, зелёным, упомянутые через @. У области видно, что в ней лежит, например «Карты мира · 4 картинки, 1 заметка». В отправленном сообщении под текстом написано, какой контекст к нему приложен.

Агент помнит переписку, поэтому объекты по стрелкам отправляются ему один раз и потом снова, только если они изменились: например, в область добавили картинку или поправили заметку. В новом чате они уходят заново. API-чат получает их с каждым запросом.

Действия с одним сообщением — правый клик по нему: «Копировать ответ» («Копировать сообщение»), «Ответ в заметку» (заметка появится рядом и соединится стрелкой), у API-чата ещё «Ответ в связанный терминал» и «Удалить сообщение». Если в сообщении выделен текст, первым пунктом будет «Копировать выделенный текст». При наведении на сообщение ничего не всплывает, и переписка не сдвигается.

**Файлы, которые сделал агент.** Чтобы открыть папку со скриптом, архивом или отчётом из ответа, нажмите правой кнопкой: по строке инструмента «Файлы» (Codex) или Write / Edit (Claude Code) — «Показать «имя файла» в проводнике» и «Копировать путь к файлу»; по тексту ответа — «Файлы ответа — показать в проводнике» со списком всех файлов, которые агент создал, изменил или назвал (ссылки и пути вида `C:\…` в тексте). Ссылка на файл в ответе (например, «Скачать архив») по клику тоже показывает файл в проводнике. Файл только выделяется в своей папке — ничего не открывается и не запускается. Путь без диска берётся от рабочей папки агента; если файла уже нет, откроется папка, где он был.

## 6. Лимиты

Кнопка с индикатором в заголовке показывает все лимиты, пульт — выбранные (Настройки → Лимиты).
- **Codex** — из ваших сессий в `~/.codex` (окно 5 часов и неделя).
- **Claude Code** — из вашего аккаунта, по входу Claude Code.
- **Kimi, DeepSeek, OpenRouter** — баланс по API-ключу.
- **OpenAI / Anthropic / Gemini API** — по данным последних ответов, плюс локальный учёт токенов. Суточный бюджет задаётся в настройках провайдера.

## 7. Заметки

- Хранилище — обычная папка с файлами `.md`, по умолчанию `Документы\VibeTabula Vault`. Можно выбрать свою папку, в том числе существующее хранилище Obsidian (боковая панель → «⋯» → «Выбрать другое хранилище…»).
- **Ссылки:** наберите `[[` — появится список заметок. Клик по ссылке открывает заметку. На canvas связанная заметка откроется рядом и соединится стрелкой.
- **Теги:** `#тег`. Клик по тегу фильтрует список.
- **Шрифт и размер** заметки — на панели редактора: кнопка с названием шрифта (каждый показан своим начертанием, «Другой шрифт компьютера…» — поиск по всем установленным) и поле размера (число, ↑/↓, колесо, − / +). Вид запоминается для каждой заметки отдельно и одинаков на canvas и в боковом редакторе; сами `.md` файлы не меняются (настройки хранятся в `.vibetabula/note-styles.json` в папке хранилища и синхронизируются вместе с заметками).
- Внизу бокового редактора — обратные и исходящие ссылки. Переименование заметки обновляет ссылки на неё во всём хранилище.
- **Граф связей** — кнопка с графом в боковой панели. Из графа можно вывести связанные заметки на canvas.
- **На canvas:** перетащите заметку из списка, кнопка «На canvas» в редакторе или ПКМ → «Вывести со связями».
- **Несколько заметок:** Ctrl+клик добавляет заметку к выбору, Shift+клик выбирает диапазон. Выбранные можно перетащить на canvas все сразу (они встанут ровной сеткой на свободное место, не налезая на другие объекты), перетащить на папку, чтобы переместить, или через ПКМ: «Вывести на canvas», «Переместить в папку», «Удалить».
- **Слои.** Вкладка «Слои» рядом с «Заметками» — список объектов текущего canvas. Области показаны группами со своим содержимым (стрелка сворачивает). Клик выделяет объект на canvas, Ctrl+клик — несколько, Shift+клик — диапазон, двойной клик — перелететь к объекту, ПКМ — то же меню, что на canvas. Замок на строке закрепляет объект, при наведении на строку объект подсвечивается. Выделение на canvas подсвечивается в списке.

**Панель инструментов заметки:**
- **Aa** — стили: заголовок, подзаголовок, основной текст, моноширинный; жирный, курсив, подчёркнутый, зачёркнутый, маркер, код; списки, чек-лист, цитата, разделитель.
- Чек-лист, таблица (повторный клик внутри таблицы — добавить или удалить строки и столбцы), вложение-картинка, ссылка, отмена.
- Шрифт и размер заметки, жирный, курсив и остальное — на той же панели. Если панель не помещается (узкое окно, маленькая заметка на canvas), лишние кнопки уходят в меню **⋯**.
- **На canvas:** выделите текст в заметке — над ним появится плавающая панель: Aa (заголовки и списки), жирный, курсив, подчёркнутый, зачёркнутый, маркер, код, ссылка, чек-лист. Панель заметки со шрифтом и размером видна, когда заметка выделена.

**Быстрая разметка при наборе:** `# `, `## `, `### `, `- `, `1. `, `[] `, `> `, ` ``` ` + Enter, `---` + Enter, а также `**жирный**`, `*курсив*`, `~~зачёркнутый~~`, `` `код` ``, `==маркер==`.

## 8. Внешний вид

- **Тема:** кнопка ☀/☾ в заголовке или Настройки → Общие → Тема (тёмная, светлая, как в системе).
- **Миникарта:** кнопка с картой у масштаба, клавиша `M` или Настройки → Общие.
- **Питомец** живёт в пульте: нажмите на него, и он расскажет, что делают агенты. **Сменить питомца:** ПКМ по питомцу, кнопка ⟳ в его углу или Настройки → Общие → «Выбрать питомца…». На выбор: Блонди, Лисёнок, Робот Бип, Кодер, Дракончик, Аксолотль, Гугагага, Чиби-волшебница. **Свой питомец:** в том же окне загрузите любую картинку (PNG с прозрачным фоном или анимированный GIF), по желанию отдельные картинки для «агенты работают» и «агентов нет». Маленькая копия питомца бегает за курсором, это отключается в настройках.

**Питомцы Codex.** VibeTabula понимает питомцев из приложения Codex: анимированных персонажей с листом из 9 (или 11) строк анимации. В окне выбора питомца нажмите «Каталог codex-pets.net»: там больше 3500 питомцев сообщества, поиск и сортировка (популярные, новые, случайные…). При наведении превью оживает, «Установить» скачивает питомца в `~/.codex/pets` (ту же папку, что у Codex, так что он появится и там) и сразу делает его вашим. Питомцы, установленные через Codex или `npx codex-pets add …`, тоже видны в списке.

Питомец Codex ведёт себя как в Codex:
- сидит в углу canvas и показывает, что делают агенты: **работает** (агент занят), **ждёт ответа** (агенту нужно разрешение или выбор — VibeTabula видит такие вопросы в терминале и в окне чата), **готово, посмотрите** (задача закончилась, а вы ещё не открывали окно), **ошибка**;
- над ним пузырь с именем агента; клик по пузырю или по питомцу открывает это окно;
- клик — машет, двойной клик — прыгает, а когда агент заканчивает задачу, питомец радостно подпрыгивает;
- его можно перетащить в любое место: пока тащите, он бежит в ту сторону, а при отпускании прыгает;
- питомцы с 11 строками (значок 👀 в каталоге) поворачивают голову за курсором;
- ПКМ — меню: размер, вернуть в угол, сменить питомца, спрятать.
В пульте агентов показывается тот же питомец с тем же состоянием. Если в системе включено «уменьшение движения», анимация останавливается.
- **Колесо мыши:** масштаб или прокрутка (Настройки → Общие).

### Плавность и FPS
- **Ctrl+Shift+F** — счётчик кадров в углу окна (зелёный — 58+ FPS).
- **Ctrl+P → «Тест плавности»** (или Настройки → Общие → Производительность) — canvas около 10 секунд сам двигается, масштабируется и перетаскивает объект, затем показывает FPS, видеокарту и экран. Если там написано, что аппаратное ускорение выключено, обновите драйвер видеокарты: без него интерфейс рисует процессор.

## 9. Синхронизация между компьютерами

VibeTabula синхронизирует проекты, canvas со всеми окнами и стикерами и историю чатов через общую облачную папку: iCloud Drive, Dropbox, Google Drive, OneDrive, Яндекс Диск, Syncthing или сетевой диск. Сервер и регистрация не нужны, работает между Windows, macOS и Linux.

1. На первом компьютере: Настройки → Синхронизация → «Выбрать…» и укажите папку в облаке, например `C:\Users\вы\iCloudDrive` или папку Dropbox. В ней появится `VibeTabula Sync`.
2. На втором компьютере выберите ту же облачную папку. Если VibeTabula там только что установлен, он просто получит все проекты; если там уже есть свои проекты, они объединятся.
3. Дальше всё происходит само: изменения уходят в папку сразу после сохранения, а чужие приходят в течение нескольких секунд, как только облако их скачает.

Как решаются конфликты: canvas объединяются по объектам. Если на двух компьютерах меняли разные окна или стикеры, сохранятся все правки; если один и тот же объект — более позднее изменение. Удаление тоже синхронизируется.

Что остаётся на каждом компьютере своим: рабочие папки проектов (пути на Windows и macOS разные), положение и масштаб canvas, путь к хранилищу заметок. API-ключи по умолчанию не синхронизируются; включите «API-ключи», только если доверяете облачной папке.

**Заметки** — обычные `.md` файлы. Кнопка «Перенести в папку синхронизации» копирует хранилище в `VibeTabula Sync/Заметки` и переключает VibeTabula на него, дальше облако синхронизирует их само. На втором компьютере нажмите ту же кнопку.

## Безопасность

- **Незнакомые команды.** Перед запуском команды, которая ещё не запускалась на этом компьютере, VibeTabula показывает системное окно с самой командой. Так бывает, например, когда команду агента поменяли на другом компьютере и она пришла через синхронизацию. Если вы её не задавали, нажмите «Отмена». Команды, которые вы вписали в Настройки → Агенты на этом компьютере, и стандартные агенты запускаются без вопроса. Список разрешённых команд хранится только на этом компьютере и не синхронизируется.
- **HTML из заметок, синхронизированных canvas и буфера обмена** очищается: скрипты, обработчики событий, встроенные фреймы и опасные ссылки удаляются.
- **Ссылки** открываются в браузере, только если это `http`, `https` или `mailto`. Ссылки вида `file:`, `smb:`, `search-ms:` и другие, способные запустить программу, игнорируются.
- **Веб-страницы на canvas** изолированы. У них нет доступа к камере, микрофону, геолокации, файлам и приложению, а открыть они могут только `http`/`https`.
- **API-ключи** хранятся на диске зашифрованными системным хранилищем (Windows DPAPI, связка ключей macOS). В синхронизацию они попадают, только если вы это включили.

## 11. Где хранятся данные

- Проекты, canvas, настройки и API-ключи: `%APPDATA%\VibeTabula` (`workspace.json`, папка `canvases`).
- Заметки: папка хранилища (по умолчанию `Документы\VibeTabula Vault`).
- Обновление приложения: замените папку `dist\VibeTabula-win32-x64`. Данные останутся на месте.

## 12. Если что-то не работает

- **«Команда не найдена» / «Статус недоступен»** — агент не установлен или не виден. Установите его (команды ниже) и перезапустите VibeTabula. Если агент стоит в нестандартном месте, укажите полный путь в Настройки → Агенты.
- **Окно чата агента сразу выдаёт ошибку входа** — нажмите «Войти» под ошибкой: откроется терминал со входом (у Claude Code введите `/login`), потом «Повторить».
- **Чат по API: «Нет API-ключа» или ошибка 401** — проверьте ключ в Настройки → API-провайдеры.
- **Подтормаживает** — скройте миникарту (M), отключите бегающего питомца, держите неиспользуемые терминалы закрытыми или отдалитесь: при сильном отдалении окна становятся лёгкими карточками (порог — в настройках, «Карточки при отдалении»). Окна, ушедшие за край экрана, не отрисовываются.
- **Терминал не открывается** — нужен .NET Framework 4 (есть в Windows 10/11). Удалите папку `%APPDATA%\VibeTabula\bin` и откройте терминал снова.

Установка агентов:
```
npm i -g @anthropic-ai/claude-code   # Claude Code
npm i -g @openai/codex               # Codex
npm i -g @google/gemini-cli          # Gemini CLI
uv tool install kimi-cli             # Kimi
```

## 13. Для разработчика

- `main/` — главный процесс Electron: окно и хранилище (`main.js`), терминалы (`pty.js`, `pty/ptybridge.cs`), окна чата агентов (`agentchat.js`; каждый ответ идёт в отдельном фоновом процессе `agent-runner.js`, который пишет журнал в `%APPDATA%\VibeTabula\agent-runs`), API-чаты (`chat.js`), лимиты (`limits.js`), заметки (`vault.js`).
- `renderer/` — интерфейс: движок canvas (`js/canvas.js`), объекты (`js/nodes.js`), пульт (`js/hub.js`), редактор заметок (`js/editor.js`, `js/md.js`), заметки и граф (`js/notes.js`), оболочка (`js/app.js`), стили (`styles.css`), эта инструкция (`help.md`).
- `renderer/vendor/` — xterm.js и marked (лицензия MIT).
- Тесты: `npm test` — синтаксис, юнит-тесты и интерфейс в браузере; `npm run test:electron` — настоящее приложение в Electron с временным профилем. Подробности в `tests/README.md`. На GitHub тесты запускаются на каждый push (Windows и Linux).
