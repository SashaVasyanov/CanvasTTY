# Changelog

## 1.1.0

- Окна чата для Claude Code и Codex «как в их приложениях»: работают по подписке через CLI, показывают команды и правки файлов, продолжают сессию.
- Светлая тема и режим «как в системе».
- Области с названиями (бывшие фреймы) и галерея фото с просмотром.
- Выбор питомца: 6 готовых (сгенерированы gpt-image), 2 нарисованных вручную и свой питомец из картинки или GIF, с отдельными картинками для «работает» и «спит».
- Скрытие миникарты (клавиша M), встроенная инструкция (F1), новый логотип.
- Оптимизация: панорамирование примерно в 3 раза плавнее, зум примерно в 2 раза. Окна за краем экрана не рисуются, во время движения поля работает только композитинг, фон с точками стал растровым.

## 1.0.0

- Бесконечный canvas: выделение рамкой, перемещение, resize, умные направляющие, выравнивание, слои, стрелки, undo/redo, миникарта, карточки при отдалении.
- Агенты в терминале (ConPTY-мост на Windows без нативных модулей), API-чаты со стримингом, лимиты Codex и Claude Code.
- Заметки в стиле Obsidian: вики-ссылки, обратные ссылки, теги, граф, редактор с панелью как в Apple Notes.
- Проекты и несколько canvas на проект.
