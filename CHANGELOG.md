# Changelog

## 1.4.0

- Питомцы Codex: каталог codex-pets.net в приложении (поиск, сортировка, живые превью, установка в ~/.codex/pets — общая папка с Codex), питомцы из Codex и `npx codex-pets` видны автоматически.
- Поведение как в Codex: состояния «работает», «ждёт ответа», «готово, посмотрите», «ошибка» с пузырём и переходом к окну агента, взмах по клику, прыжок по двойному клику и после завершения задачи, бег при перетаскивании, взгляд за курсором у 11-строчных питомцев, меню с размером.
- Двойной клик по пустому месту canvas больше не создаёт стикер (стикер — клавиша S или кнопка на панели).
- CanvasTTY замечает, когда агент ждёт ответа: вопросы о разрешении в терминале Claude Code / Codex и нехватку прав в окне чата.

## 1.3.0

- Синхронизация между компьютерами через облачную папку (iCloud Drive, Dropbox, Google Drive, OneDrive, Яндекс Диск, Syncthing): проекты, canvas и история чатов, объединение правок по объектам, перенос заметок в облачную папку. API-ключи по желанию.
- Цвета часов: 11 готовых наборов и свои цвета, отдельно для тёмной (по умолчанию StandBy) и светлой (по умолчанию «Бумага») темы. ПКМ по часам — быстрый выбор.
- macOS: сборки для Apple Silicon и Intel (.dmg и .zip), родные кнопки окна, меню с Cmd+C / Cmd+V, PATH из оболочки входа (находит claude и codex из Homebrew и npm).
- Рабочая папка с другого компьютера, которой здесь нет, заменяется домашней.

## 1.2.0

- Новый объёмный логотип — медное перо. Он же стал иконкой приложения, ярлыка и установщика.
- Окно чата агента: выбор модели (Opus, Sonnet, Haiku, Fable 5.1 у Claude Code, модели Codex или любая своя) и уровня размышления. «Авто» берёт значения из настроек агента и показывает, какие именно.
- Строка состояния в окне чата: полный путь рабочей папки и модель, которой реально работает агент.
- Конкретные версии моделей Claude: Opus 5.5 / 5 / 4.8 / 4.7 / 4.6 / 4.5, Sonnet 5.5 / 5 / 4.6 / 4.5, Haiku 5.5 / 4.5, Fable 5.1 / 5.
- Двойной клик по окну, заметке или области включает перемещение за любое место.
- ПКМ по области → «Ввести название…».
- Области стали группами: объекты внутри принадлежат области, счётчик объектов, подсветка при перетаскивании, вложенные области, копирование вместе с содержимым, режим «двигать как одно целое» (Ctrl + клик — объект внутри), разгруппировка.
- Плавность: перетаскивание объектов, выделение и сетка фона работают через композитинг без перерисовки, связи обновляются точечно, движение мыши обрабатывается раз в кадр. Счётчик FPS (Ctrl+Shift+F) и встроенный «Тест плавности» с данными о видеокарте.
- Ярлык берёт иконку из самого CanvasTTY.exe и обновляет кэш иконок Windows.
- История чатов: панель слева в окне чата, автосохранение разговоров, поиск, продолжение старых чатов. Для агентов — сессии Claude Code и Codex с диска, в том числе из терминала.
- Часы в пульте в стиле iPhone StandBy, с датой.

## 1.1.0

- Окна чата для Claude Code и Codex «как в их приложениях»: работают по подписке через CLI, показывают команды и правки файлов, продолжают сессию.
- Светлая тема и режим «как в системе».
- Области с названиями (бывшие фреймы) и галерея фото с просмотром.
- Выбор питомца: 6 готовых (сгенерированы gpt-image), 2 нарисованных вручную и свой питомец из картинки или GIF, с отдельными картинками для «работает» и «спит».
- Скрытие миникарты (клавиша M), встроенная инструкция (F1), новый логотип.
- Оптимизация: панорамирование примерно в 3 раза плавнее, зум примерно в 2 раза. Окна за краем экрана не рисуются, во время движения поля работает только композитинг, фон с точками стал растровым.

## 1.0.0

- Бесконечный canvas: выделение рамкой, перемещение, resize, умные направляющие, выравнивание, слои, стрелки, undo/redo, миникарта, карточки при отдалении.
- Агенты в терминале (ConPTY-мост на Windows без нативных модулей), API-чаты со стримингом, лимиты Codex и Claude Code.
- Заметки в стиле Obsidian: вики-ссылки, обратные ссылки, теги, граф, редактор с панелью как в Apple Notes.
- Проекты и несколько canvas на проект.
